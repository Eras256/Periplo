## Testnet, not mainnet

Everything this site shows happens on Stellar testnet. Nothing here is a mainnet service, and no part of the site should be read as if it were. **Periplo does not operate on mainnet yet.**

## Not advice

Nothing on this site is financial, investment, legal or tax advice.

## No token, no offering

Periplo issues no tokens and offers no investments. PTEST is a testnet asset with no value.

## No affiliation

Periplo is an independent open-source project. It is not affiliated with, endorsed by or sponsored by the Stellar Development Foundation. "Stellar" is used only to describe the network the software runs on.

## Security status

Periplo **has not had an external security audit**. The repository includes a [threat model](https://github.com/Eras256/Periplo/blob/main/docs/THREAT-MODEL.md) and automated dependency checks, which are not a substitute for an audit.
